Затем для каждого сервера wss://<url>:<port> отправляем 000E050000000000002C00000000 (из C# кода, в ТЗ также 000A0500000000000021), ждем тег 6, разбираем отступ 6608 — топ 3 игрока (позиция, имя, масса, ID, бейдж).
Деплой: залейте папку на GitHub Pages (ветка gh-pages / docs / main root).
